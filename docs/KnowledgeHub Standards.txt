Version Number Format
-------------------------------------------------------------------------------

Versions shall be zero padded.

Examples

VERSION#000001

VERSION#000002

VERSION#000010

VERSION#000125

This ensures correct lexical ordering.

===============================================================================
11. VERSIONING RULES
===============================================================================

Every uploaded file creates one immutable version.

Versions shall never be modified.

Versions shall never be overwritten.

Restoring a version creates a brand-new version.

Restored versions reference the original S3 object.
